\# Suspicious PowerShell Detection



\## Status



Draft — not yet validated against live telemetry.



\## Objective



Identify PowerShell executions that contain characteristics commonly associated

with suspicious or malicious activity while reducing alerts generated by normal

PowerShell usage.



\## Detection Logic



Generate an alert when PowerShell executes and at least one suspicious

condition is present.



Initial suspicious conditions:



\- PowerShell is launched by Microsoft Word (`WINWORD.EXE`)

\- The PowerShell command line contains `-EncodedCommand`



\## Rationale



PowerShell is commonly used for legitimate administration and automation.

Alerting on every PowerShell execution would generate excessive noise.



The detection therefore focuses on higher-risk contextual indicators such as:



\- unusual parent-child process relationships

\- encoded PowerShell commands



These indicators are not proof of malicious activity and require analyst

investigation.



\## Investigation Fields



The analyst should review:



\- User

\- Endpoint

\- Process

\- Parent process

\- Command line

\- Timestamp

\- Related processes

\- Network connections

\- Files created

\- Activity occurring before and after execution



\## Initial Investigation Questions



1\. Is PowerShell usage expected for this user?

2\. Is the parent process legitimate?

3\. What does the command actually execute?

4\. Is the encoded content benign or suspicious?

5\. Did PowerShell create additional processes or files?

6\. Did PowerShell establish network connections?

7\. What happened immediately before and after the event?



\## Expected False Positives



Possible legitimate causes include:



\- administrative automation

\- software deployment

\- management tools

\- approved scripts

\- legitimate encoded PowerShell usage



\## Future Tuning



After live testing, evaluate:



\- known legitimate parent processes

\- trusted administrators

\- approved scripts

\- known management tools

\- frequency thresholds

\- additional suspicious command-line indicators



\## Success Criteria



The detection should identify intentionally generated suspicious PowerShell

activity in the lab while avoiding alerts for ordinary PowerShell usage where

possible.
